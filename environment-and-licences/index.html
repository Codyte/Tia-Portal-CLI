Check the TIA Portal environment, licences and knowledge base

The verbs that answer before a project is open. They report which TIA Portal versions and options are installed, which licences the Automation License Manager holds — which is what a LicenseNotFound answer really means — and run a batch of calls in one session.

tia help <verb>

tia env
ring 0, no Portal needed: what is on this machine
tia licenses [--like X]
ring 0, no Portal needed: the Automation License Manager inventory, read-only
tia snapshot
full inventory: devices + blocks + tables + UDTs of the whole PLC
tia find --pattern "*" --kind tag
every tag
tia run --script ops.json | --steps ops.txt [--check] [--summary] [--digest] [--fail-fast] [--from N] [--atomic | --rehearse]
JSON array of arg-arrays, a single session
tia version | --version
version of the CLI + which Openness installation this exe loads
