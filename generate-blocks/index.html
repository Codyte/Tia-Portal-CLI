Generate and import TIA Portal blocks in SCL and ladder

Where an AI agent actually programs the PLC. Blocks arrive as SCL sources or as SimaticML XML, which is the only route to ladder (LAD) and FBD. Writes are previews until --apply, so a generated block can be reviewed before it reaches the project.
