Install and harmonise a TIA Portal global library by command

A library is how one engineered solution reaches many projects. These verbs create and read global libraries, install a whole library on a PLC, check which project types are behind their library version, and harmonise the project against it.

24 verbs of 348 · TIA Portal V19, V20 and V21
