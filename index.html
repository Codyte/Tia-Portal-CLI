348 verbs for Siemens TIA Portal, from the command line

Tia-Portal-CLI is a local command line between an AI agent and the Siemens TIA Portal Openness API. It takes plain flags and answers JSON, so a model can read a project, generate blocks in SCL or ladder, configure hardware, compile and go online without a human clicking through the editor. Writes are previews until an explicit --apply, and nothing leaves the engineering machine.
