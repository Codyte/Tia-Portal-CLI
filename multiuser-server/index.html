TIA Portal Multiuser server sessions from the command line

Multiuser engineering without the GUI: find the servers and their projects, add a project to a server, create and open a local session, and commit it back.

12 verbs of 348 · TIA Portal V19, V20 and V21

tia list-servers
read-only: Project Server connections stored in the Portal configuration
tia list-server-projects --server HOST [--port N] [--http] [--keep-connection]
read-only: projects of the TIA Project Server, lock and local sessions
tia add-project-to-server --server ALIAS --file X.ap21 [--port N] [--http] [--apply]
publishes a single-user project on the server
tia create-session --server ALIAS --project P --name N --dir D [--exclusive] [--port N] [--http] [--apply]
creates a local session of the server project
tia open-session --file X.amc21 [--server-project]
opens an existing local session
tia delete-session --server ALIAS --project P --session ID [--port N] [--http] [--apply]
deletes the local session on the server
tia commit-session --comment "text" [--apply]
check-in of the local session: it saves, sends to the Project Server and CLOSES the session
tia list-server-groups --server ALIAS [--port N] [--http] [--keep-connection]
read-only: the groups of the Project Server and the projects of each one
tia list-markings [--conflicted]
read-only: what is marked for check-in in the LOCAL SESSION, object by object, with the mark state (IsMarkedByMe/IsMarkedByOthers/IsUptoDate)
tia mark-state --name X
read-only: mark state of one symbol (block, tag, table or UDT) plus whether it is markable at all
tia mark-object --name X [--apply]
marks the symbol for check-in in the local session
tia unmark-object --name X [--apply]
the pair of mark-object: takes the symbol out of the check-in
