Configure Siemens PLC hardware from the command line

The hardware configuration as data. These verbs read the catalogue, add and delete devices, plug modules into slots, and read or set any attribute Openness exposes on a device, so a rack can be built or audited without opening the editor.

46 verbs of 348 · TIA Portal V19, V20 and V21

tia list-catalog --like F [--for TYPEID] [--max N]
read-only search in the Portal's hardware catalog, no project needed
tia add-device --mlfb "6ES7 ..." --name X [--station S] [--group G] [--apply]
an --mlfb with no /Vx.y takes the highest version in the catalog, and the answer says which
