Download, upload and compare a Siemens PLC online

The online boundary. These verbs scan the network for reachable targets, go online, download or upload a station, and compare what is in the PLC against what is in the project before anything is written.

9 verbs of 348 · TIA Portal V19, V20 and V21

tia online-state [--plc X]
read-only: connection state of the PLC (Offline/Online/NotReachable/...), whether the access configuration was ever made (isConfigured) and the connection modes
tia list-online-targets [--plc X]
read-only: the whole access tree
tia net-scan [--pc-interface X]
read-only: what answers on the network (DCP, the GUI's Accessible devices) on each PC interface
tia go-online [--plc X] [--pc-interface PLCSIM] [--answer Question=Selection] [--user U] [--password-env VAR | --password P] [--target T] [--apply] [--allow-physical]
applies the access configuration and connects
tia go-offline [--plc X] [--apply]
disconnects
tia download [--plc X | --device D] [--pc-interface PLCSIM] [--options hardware,software] [--answer Question=Selection] [--password-env VAR | --password P] [--target T] [--to-dir DIR] [--apply] [--allow-physical]
--to-dir writes the download into a folder instead of a station: the only route for a WinCC Unified PC RT, which has no connection configuration
tia upload-station --device D [--pc-interface PLCSIM] [--answer Question=Selection] [--password-env VAR | --password P] [--apply] [--allow-physical]
uploads a station that is ACCESSIBLE on the network into the project
tia fingerprint-station --device D [--pc-interface PLCSIM] [--answer Question=Selection] [--password-env VAR | --password P] [--allow-physical]
read-only: the fingerprint of a station that answers on the network, for a quick station compare
tia compare-software [--plc X] [--to OTHER-PLC] [--max 200]
read-only: without --to it compares the PLC software against the CONNECTED CPU (CompareToOnline, needs go-online first)
