Open, create and archive a TIA Portal project from the command line

Every other verb needs an open project. These verbs own the session: they start a TIA Portal, open or create the project, answer the UMAC prompt of a protected one, save it elsewhere, archive it, and read or set the Portal's own settings.

10 verbs of 348 · TIA Portal V19, V20 and V21

tia open-project --file X.ap21 [--no-ui] [--user U [--kind project|global] --password-env VAR | --password P]
--user answers the UMAC question of a protected project, and umac.asked says whether it was really asked
tia create-project --dir D --name N [--no-ui] [--major N]
--major picks the installed worker of that Portal major and starts its Portal
tia save-project
See the verb's own --help.
tia close-project [--save]
See the verb's own --help.
tia delete-project --dir D [--apply]
removes a disposable ZZ_TESTE_* project in one call: closes it unsaved in any Portal that has it open, then deletes the folder D and its D.backup sibling
tia save-project-as --dir D [--apply]
Save As of the open project
tia save-library-as --file LIB.al2x --dir D [--apply]
Save As of a user global library
tia archive-project --dir D [--name N] [--compressed] [--discard-restorable] [--apply]
backup of the PROJECT as .zapXX
tia list-portal-settings [--like X]
read-only: the TIA Portal's own settings (Options > Settings) as Folder/Name with value and type
tia set-portal-setting --name Folder/Setting --value V [--apply]
one Portal setting
