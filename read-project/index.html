Read a Siemens TIA Portal project from the command line

The largest family, and the one an AI agent calls first. Nothing here changes the project, so these verbs are safe to run against a live engineering project: they list and export blocks, tags, types, devices, networks and cross-references, and print the project tree in a form a model can read.
